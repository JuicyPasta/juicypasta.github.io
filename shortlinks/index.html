Copy links between Chrome profiles

Links are saved in Chrome sync for the Google account a Chrome profile is signed in to, so each account has its own set. To copy them, export here and import in the other profile (open this page there too).

For scripts and browser agents

From this page's console: await shortlinks.list() returns {prefix, version, links}; shortlinks.save(name, url), shortlinks.rename(oldName, name, url), shortlinks.remove(name), shortlinks.importLinks({name: url}, overwrite). To open a link, go to http://go/name.

This page is a static file. It reads your links from the Shortlinks extension inside this browser and never sends them anywhere. To change the prefix, type go/ in the address bar to open the extension's own page.
